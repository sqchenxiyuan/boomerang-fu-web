# 与 Godot 参考实现对齐（模拟 0.8.0）

本轮把底层玩法、数值和机制改为参照公司 Godot 移植版的模拟层：`Arkevo-Lab/arkevo-games` 的 `games/boomerangfu/godot/core/`（读取时为 `main` 分支 `2dc396ef`）。只移植运动、战斗、计时与计分规则；地图、模型、贴图和音效保持本仓库原有实现。

## 单位换算

参考实现使用 Unity 坐标（Y 向上）。Web 世界坐标为 `x = Unity.x × 0.4`、`y = −Unity.y × 0.4`，与 `src/core/original-map-data.json` 的地图导出一致。所有距离、速度和力在 `src/core/config.ts` 的 `NATIVE` 中乘以 `0.4`；时间（秒）、阻尼（1/s）、弹性系数和比例不缩放。镜像只翻转手性：自旋、近战多边形左右等用同一套 Web 公式计算，方向关系与参考实现一致。

角色半径因此从 Web 原先的 `0.47` 改为参考值 `0.66 × 1.33 × 0.4 ≈ 0.351`，飞镖墙体查询半径为 `0.5 × 0.4`，触发半径为 `0.7125 × 0.4`。

## 有意保留的差异

- **镜头镜片。** 移植的是取景逻辑，不是镜片：Web 保留自己的 FOV 31° 与俯角，把参考实现的 `zoom ÷ 最大 zoom` 乘到原有的全图距离上，焦点用参考的加权中心。完全拉远时与改动前的固定全景一致，像素风按镜头范围体素化的逻辑不受影响。场景物件镜头目标（`original_camera_scenery.gd`）、道具书目标、稳镜噪声没有接入；击杀拉镜只检查进行中的爆炸，不检查移动障碍；Web 爆炸是瞬时的，镜头目标按 0.5 s 保留。`renderer.dynamicCamera = false` 可切回固定全景。
- **慢动作的实现方式。** Unity 在慢动作中减少 FixedUpdate 次数。Web 仍然每个渲染帧推进一次，并使用 `dt × timeScale`，以保持 SDK 和录像的固定 60 Hz 契约以及画面平滑。冻结帧会跳过整帧。
- **数值精度。** 计算使用 JS 双精度，没有模拟 float32 和 Unity/.NET 随机数序列，所以不能与参考实现的 trace 逐帧比对。
- **地面元素。** 火、冰仍然是 Web 的圆形区域，没有移植参考实现的 `CellGrid`、液体溅洒、涉水和黏液。冰冻角色会按参考实现继续滑动（阻尼 2）。
- **挤压。** 移动障碍仍使用 `environment.ts` 的推出与压死判定；被夹的飞镖直接返还主人，没有 `SQUISHED` 停留阶段。
- **追踪半径。** 所有角色都使用键盘值 11（手柄在参考实现中为 7）。
- **AI。** 只移植了难度参数，并加了一个 Web 版的落水冲刺自救（按难度给出成功概率，参考 AI 没有专门的这一分支）。参考实现中基于效用打分的 PlayerAI 没有移植。
- **爆炸。** 半径与持续伤害窗口仍是 Web 的即时采样；参考实现中的护盾击退和击杀归属已经接入。爆炸镖只在引信到期时爆炸，之后 1.75 s 补发武器（分裂爆炸镖为 3.25 s）。
- **开场发镖。** 开场仍在 Go 之后 1.2 s 发镖，与 Web 的入场演出绑定，没有改成参考实现的 `RespawnDiscRoutine(1.75)`。
- **环境交互。** 开关、植物、木箱仍按 Web 原有的近战半径与扇形判定。
- **其他模式。** 躲猫猫、组队、黄金回旋镖、落后自动护盾没有接入。

## 兼容性

- `SIMULATION_VERSION` 改为 `0.8.0`。0.6/0.7 录像会被拒绝导入，因为同一组输入在新物理下结果不同。
- 之后的 0.9.0 只把三角函数换成跨引擎确定的实现（`src/core/dmath.ts`），机制与参数不变。
- `MatchOptions.scoring`：`'kills'`（默认）或 `'survival'`（旧规则：最后存活得 1 分，先得 5 分）。`scoreGoal` 可以省略，省略时按计分方式和人数取默认值。
- `Difficulty` 新增 `'impossible'`。
- 新增的角色和飞镖字段都是可选的，旧快照仍可读取；`Disc.state` 仍是粗粒度投影，细分状态见 `Disc.movement`。

## 验证

- `npm test`：全部通过，新增 `tests/godot-parity.test.ts` 覆盖时间系统、近战多边形、对砍、缴械与公共镖、飞镖生命周期、自由滑行、召回、自旋、飞镖互撞、护盾、冲刺撞人、推落归属和连杀。
- 旧测试中断言旧行为的部分已改为参考实现的语义，每处都写了注释说明来源。依赖旧规则的场景（多回合录像、地图冒烟）显式使用 `scoring: 'survival'`。
- 本轮没有在真实浏览器中验证：开发机缺少 Chromium 运行库（`libnspr4`），系统 Chrome 也未安装。渲染层只做了类型检查和已有的离屏测试。
