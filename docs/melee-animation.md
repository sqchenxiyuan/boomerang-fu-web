# 普通攻击动画改进 · 0.4.1

2026-10-29。针对 J 键普通攻击的反馈，重做 Web 角色动作和武器轨迹。此前手臂沿 X 轴上下摆，横向弧光独立转动，攻击结束后立即恢复站姿；现在身体、手臂、武器与拖影共用动作进度。

- 约 28 ms 短起手、100 ms 快速横挥、70 ms 顺势带过，再在约 380 ms 时完成收招。伤害窗口仍为 200 ms，攻击冷却仍为 660 ms，收招只影响画面。
- 身体先反向转动再横向发力，配合轻微压缩、前倾与前脚踏步。手臂连接肩膀和手的位置，武器随手划过前方；副手保持防守，双镖可见。
- 空手使用前推的动作，不显示武器刀光。诱饵清除从主人复制的攻击和恢复计时，避免主人挥击时诱饵也出现攻击姿态。
- 取消旧的整片扇形弧光和未使用的角色 slash mesh。两层羽化弧线按镖尖的近期扫过角度生成，四名角色共用一个 draw call 和固定容量缓冲。
- 表现读取现有 `attackTime`、`lungeRecovery`，并用 `alpha` 做帧间采样；没有增加模拟字段或额外推进时钟。区分投掷冷却，避免投镖时错误重播挥砍。
