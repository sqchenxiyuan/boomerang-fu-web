# 角色动作、像素风（体素）画面与机器人闪避

## 夸张动作与悬浮手脚

角色的手和脚不再用手臂连着身体，而是悬浮在身体两侧和下方。它们挂在一个只跟随朝向旋转的骨架上，所以身体挤压拉伸时，手脚不会跟着变形。具体姿态由 `src/rendering/character-motion.ts` 里的 `sampleCharacterPose(actor, animation, { throwAge })` 计算。

### 与 Godot 对齐的显示层

移动时的“抽搐”来自两处：旧版的步伐相位直接用“模拟时间 × 速度”计算，速度每帧有细微波动，t = 30 s 时 1% 的变化就会让步伐相位跳约 2.7 弧度；另外，朝向没有插值，并且姿态按 60 Hz 的模拟步取时间。现在这一层按 Godot 版本的实现移植：

- **插值**：每个模拟步记下上一帧的位置和朝向。渲染时位置用 `lerp(previous, current, alpha)`，朝向用 `lerp_angle`（走最短的方向）。冻结帧期间整个世界静止，不再在最后两步之间来回插值。
- **片段播放**（`src/rendering/character-animation.ts`，移植自 `OriginalCharacterPreview.advance` 和 `main.gd`）：
  - **走动速度** `move_speed_parameter` = min(|速度| / 11, 2)。用的是阻尼前的速度，Web 存的是阻尼后的速度，换算回来。冰面上乘以 2 倍滑动系数（最多到 1），突刺时为 0，低于 0.25 记为 0；眩晕、冰冻、冲刺期间保持上一帧的值。
  - **片段选择顺序**：死亡（被烧死时用烧焦片段）、冰冻、眩晕、坠落；都不是时，速度大于 0.25 用走路片段（按手里飞镖数分为 0 / 1 / 2 三种），否则待机。
  - **切换片段**时从头播放；同一个片段不重置。挥砍结束后，基础片段从头开始。
  - **片段时间**每帧累加“真实帧时长 × 游戏时间缩放 × 回放倍速 × 片段速度”。待机速度 0.65，走路速度等于 `move_speed_parameter`。速度变化只改变播放快慢，不会让相位跳变。
  - **时长**（参考值）：待机 1.3167 s 循环；走路 0.65 s 循环，一个循环迈两步；眩晕 0.75 s；坠落 0.7667 s。满速走路时 `move_speed_parameter` ≈ 1.65，所以走路循环约 0.39 s。
- **朝镜头倾斜**（`TiltActorTowardsCamera`）：模型整体向镜头倾斜 25°，并向镜头方向偏移 `BODY_OFFSET`（0.4 个 Unity 单位，即 Web 的 0.16）。地面上的光环、影子、瞄准线不倾斜。

照搬的只是这些逻辑和时间参数，姿态本身仍是本仓库的程序化动作。原版导出的骨骼动画曲线（例如 `Avocado-walk.json`）属于原作的美术资源，没有复制进这个公开仓库。

| 状态 | 表现 |
| --- | --- |
| 待机 | 身体呼吸起伏，双手上下浮动、相位错开 |
| 跑动 | 每个走路循环迈两步，每一步都有腾空和落地压扁；身体前倾、左右摇摆；双手反向摆动，拿两支飞镖时摆幅变小、空手时变大；脚走弧线 |
| 蓄力 | 躯干扭开并后仰，投掷手拉到身后高处，另一只手指向前方；蓄满时轻微发抖 |
| 投掷后 0.36 s | 带回弹的甩出：躯干转过身体中线，投掷手扫到另一侧，身体向前拉伸 |
| 挥砍 | 在原有挥砍曲线上把扭转、前倾、踏步和挤压拉伸都放大，另一只手向后平衡 |
| 冲刺 | 沿运动方向拉长，身体前扑，手脚甩在身后 |
| 召回 | 双手前伸，身体后仰往回拽 |
| 眩晕 / 击退 | 绕圈摇晃、手臂软垂 / 失去平衡、双手举起 |
| 下落 | 双手乱挥 |
| 冰冻 | 所有关节定格 |

蓄力、投掷、挥砍、召回、冲刺、击退这些动作叠加在基础片段上，由模拟状态驱动：例如投掷后的动作由该角色最新那支飞镖的飞行时长推出来，挥砍由模拟里的攻击计时推出来。

## 像素风（体素模型）

菜单 → 画面风格 → **像素风 · 体素方块模型**。这个模式不做降分辨率的后期处理，而是把人物、地图、飞镖、道具和特效都换成方块模型，画面仍按全分辨率渲染。选择保存在浏览器本地；SDK 浏览器入口用 `game.setVisualStyle('pixel' | 'standard')` 切换。切换后下一帧会按新风格重建所有模型。

### 转换工具

模型都是代码里程序化生成的，所以转换在运行时完成，统一由 `src/rendering/voxelize.ts` 处理，不需要另外维护一套像素素材。

1. **表面体素化**：把每个三角形保守地扫描到立方网格上。正好落在格子边界上的表面归到实体内侧，所以 y = 0 的地面顶仍在 y = 0，角色不会陷进地里。
2. **按面取材质**：每个方块的六个面，分别取法线最接近的源三角形的材质。墙顶保留墙顶的颜色、侧面保留侧面的颜色，地面上草下土。
3. **贪心合并**：同一方向、同一层里相邻且材质相同的面合并成大矩形。稀疏的层用哈希表合并，密集的层用平面掩码合并。地面的像素纹理用每格一个像素的 16×16 最近邻贴图实现，不额外增加面数。
4. **两种用法**：
   - **静态合并**：所有不会动的景物合进一个世界对齐的网格，相邻物体共用方块，看不见的底面直接剔除。
   - **原地替换**：会动的墙、地板、门、开关，以及角色的手脚、手里的飞镖、道具，都在各自的局部坐标系里替换几何体。原来的对象、变换和材质都保留，所以机关运动、变色、显隐照常工作。

   相同的基础几何体只转换一次，之后共享缓存。
5. **只转换看得见的区域**：
   - 按实际相机视锥求出地面能看到的范围。
   - 场地本身（取景框外扩 2.5）用 0.125 的方块；外围的悬崖、浮岛用 0.25 的方块，两层网格对齐拼接。
   - 高于 8 的部分截掉，顶部变平。

具体做法：

- **方块尺寸**：场景 0.125，手、脚、飞镖和道具 0.05。
- **保留原样**：Agent 身体本来就是方块加 30×30 像素脸，保持不变；名牌、光环、护盾、冰块这类半透明或发光的东西也不转换。
- **水面**：贴 8×8 的最近邻像素水纹。
- **阴影**：改为硬边。
- **特效**：粒子换成小方块，圆环和地面斑块改成八边形。

所有原版地图在 Node 里实测的转换耗时：平均每张约 90 ms，最慢的一张 0.4 s（含首次 JIT 预热），面数不超过约 4.3 万个四边形。体素是表面壳，内部不填充：从外面看不到内壁，不做填充是为了省掉一次全体积的泛洪计算。

## 默认角色

原来的四个水果角色已经去掉。默认出战的是从 Agent 工坊预设里挑的四个形象，按长相取名：

| 槽位 | 名字 | 样子 | 主色 |
| --- | --- | --- | --- |
| 1 | 红豆 | 红青双色的圆耳朵脸 | `#dc3846` |
| 2 | 紫影 | 戴面罩、头顶有刺的紫色小怪 | `#8e38dc` |
| 3 | 芝士 | 带蓝色斑点、一脸吃惊的黄色方块 | `#dcd638` |
| 4 | 薄荷 | 长角、带笑的青色猫 | `#38d1dc` |

`src/core/config.ts` 的 `ROSTER` 记录每个形象的预设种子、名字和颜色。第一次构建角色时，`src/agents/defaults.ts` 用预设种子画出形象，再用和工坊相同的方式体素化。玩家在工坊里捏的 Agent 仍会替换对应槽位，替换只影响画面，模拟和录像不变。

## 机器人闪避

`src/simulation/ai-threats.ts` 是一个只读的飞镖前向模型。它用和模拟相同的力学推算未来约 0.8 s 的飞行：投掷力、回程拉力、自由滑行、阻尼、速度上限、撞墙反弹，还有朝目标的追踪。墙体检测只取飞镖附近的障碍物。

`src/simulation/ai.ts` 在每帧规划之前先做闪避判断：

- **来袭飞镖**：同时按"原地不动"和"沿当前速度继续走"两种情况判断是否会被命中，取较早或较险的结果。
  - 还剩 0.02–0.22 s 时挥砍弹开；满蓄力的镖不弹，因为弹满蓄力镖会被击退并眩晕 0.8 s。
  - 0.42 s 内冲刺。冲刺本身无敌，所以只评估落点：落点必须是安全地面、在边界内，而且飞镖朝新位置追踪后仍然打不到。
  - 时间更充裕时，选走开后余量最大的方向，并保持一小段时间，避免来回抖动。
- **预判出手**：对手蓄力瞄准自己时会被记下，出手瞬间就算感知到这把镖，不再等反应延迟；被瞄准期间横移。
- **近战**：对方的挥砍范围已经覆盖自己时，按难度选择反砍格挡或冲刺拉开。
- **着火**：只有移动距离能灭火，所以会朝远离火焰的安全方向持续奔跑，冲刺落点也要安全。
- **边界**：后撤目标在缩圈之前也限制在边界内。

难度参数（`DODGE`）：

| 难度 | 感知延迟 | 应对概率 | 弹镖倾向 | 被瞄准时横移 |
| --- | --- | --- | --- | --- |
| 简单 | 0.40 s | 35% | 15% | 20% |
| 普通 | 0.22 s | 72% | 35% | 55% |
| 困难 | 0.12 s | 90% | 60% | 80% |
| 极限 | 0.05 s | 100% | 80% | 100% |

基准测试：一个固定且无敌的投手在 7 个单位外，随机用不蓄力、半蓄力、满蓄力朝机器人投掷，3 个种子各投 30 次，统计飞镖命中率。

| 对象 | 命中率 |
| --- | --- |
| 站着不动 | 47% |
| 简单 | 40% |
| 普通 | 32% |
| 困难 | 19% |
| 极限 | 6% |

每回合第一次出手会被开局的投掷锁定吞掉，所以命中率的理论上限约为 50%。`tests/ai-dodge.test.ts` 固定了预判精度（36 帧内误差小于 0.05）和难度排序。4 个困难机器人在原版地图上，每帧平均多花约 0.1–0.2 ms。
