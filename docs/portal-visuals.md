# 传送门光效

日期：2026-11-18。原来的传送门只是一个灰色石框，中间夹一层透明度约 43% 的彩色平面，地上一块 20% 透明度的色块，没有发光、粒子和漩涡。在浅色草地上它几乎和墙融在一起。像素风下石框会被体素化，那层彩色面却还是平滑的。这一轮只改表现，不改模拟，`SIMULATION_VERSION` 不变。实现在 `src/rendering/portal-visuals.ts`，门框本身仍在 `original-arena.ts` 的 `makeGate`。

## 先看清门是怎么摆的

- 镜头俯角约 60°（`ORIGINAL_CAMERA_UP/BACK` = 0.7/0.4），竖着的门面最多只露出一半高度。门侧对镜头时，门面几乎看不见。
- 原版 13 张图共 44 扇门，每一扇的局部 +z 侧都紧贴墙，从 -z 侧进门（`direction` 等于局部 -z）。门面原来在门框正中（z = 0），正好和墙面重合；像素风下墙体素会往外长出最多一格，于是把门面整个吞掉。现在所有光效都放在开口一侧：门面在 `-depth/2`。

所以"认得出是传送门"不能只靠门面。每扇门由五部分一起撑起来，不管门朝哪个方向，总有几样能看见：

| 部件     | 做法                                                                                 | 侧对、背对镜头时 |
| -------- | ------------------------------------------------------------------------------------ | ---------------- |
| 发光柱帽 | 两个柱帽和门楣中间的拱心石换成门的颜色，带自发光；是普通受光材质，像素风下照常体素化 | 从上方总能看见   |
| 门面漩涡 | 两条旋臂绕中心转，加一圈圈往里收的波纹；靠门柱和门楣的边缘发亮                       | 看不见           |
| 门框光晕 | 门所在平面上一圈向外衰减的光，呼吸式明暗                                             | 门顶上方能看见   |
| 地面光池 | 门前地面一片光，最亮处是门槛那条线，光环一圈圈往外推                                 | 门前能看见       |
| 光点     | 每扇门 22 个光点，从门前地面升起、飘进门里，GPU 上按种子算位置，CPU 不逐帧更新       | 能看见           |

有东西穿过时，门面、光晕、地面和光点一起变亮，0.5 秒内按模拟时间衰减（原来只是门面变白）。内置的"跃迁花园"地图用的是地上的圆形传送台，也加了同样的地面光池（圈内有漩涡）和盘旋上升的光点，原来那块半透明圆片去掉了。

## 颜色

地图给的颜色都偏粉（`#49dbd4`、`#b29bff`、`#ee7bb3`、`#f3aa56`）。按原样画在浅黄绿的草地上，紫色和草地一混就变灰。`portalTone` 在 sRGB 的 HSL 里保持色相不变，饱和度提高，亮度压到 0.45–0.62，得到 `#14dcd2`、`#6a3dff`、`#fa2e91`、`#ff8f0f`。

试过叠加混合，在浅色地面上一律洗成白色，看不出颜色，所以光效全部用普通混合。光效材质不做色调映射，好和受光的场景拉开差距，看起来是"自己在发光"。

## 像素风（主风格）

- **门面**：按体素格（0.1）取色。只有四档颜色（暗、主色、亮、白），交界处只加很轻的抖动。早先抖动幅度是 0.24，门面像电视雪花，后来降到 0.08。
- **光晕和地面光池**：不做渐变，改成两三圈实色光带；地面光池先对齐世界体素网格（和下面的地面格子一致），再换算回门的局部坐标。早先用抖动做过渡，在叠加混合下成了一片白色噪点，已去掉。
- **光点**：方形像素点（`gl_PointCoord` 不裁成圆），位置吸附到体素格。
- **动画**：和水面一样用阶梯时钟，这里是每秒 8 步。

## 成本

每扇门多 4 次绘制（光池、光晕、门面、光点），三个着色器程序在所有门之间共用，只有 uniform 不同。光点完全在顶点着色器里算，不占 CPU。只是这台机器只有软件渲染，没法给出可信的帧率数字。

## 测试

`tests/portal-visuals.test.ts`：

- 门的四个光效部件都在开口一侧，光池贴着地面、主要铺在门前；
- 光效不进体素转换，柱帽会进体素转换且是门的颜色；
- 风格切换通过共享的 `uSurfPixel` 生效；
- 穿门闪光会同时作用到所有部件，并按模拟时间衰减；
- 原版 44 扇门（包括底座沉在地面以下的门）都能建出光效，门面只覆盖地面以上的部分；
- 内置传送台有光池和光点，渲染器旋转的第一个子节点仍是那个圆环；
- `portalTone` 保持色相。
