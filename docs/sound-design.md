# 音效：程序化生成音效库

原先的音效都由几台共用合成器发出（音符 `PolySynth`、`MembraneSynth` 咚声、`NoiseSynth` 扫频噪声），所以听起来像同一类电子“哔”声，而且 Godot 版本里大约一半的游戏音效在 Web 版没有对应。现在改成用代码生成一套音效库：每个声音都按“起音 + 主体 + 尾音”分层设计，有多个变体，播放时再加随机变化。不使用任何原版音频或外部素材。

## 结构

| 文件 | 作用 |
| --- | --- |
| `src/platform/sfx/dsp.ts` | 离线 DSP 工具：可复现随机数、白/粉/布朗噪声、RBJ 双二阶滤波（参数可逐采样变化）、包络、模态合成（敲击物体）、颗粒噼啪、气泡（Minnaert 上滑音）、树叶沙沙、FM 钟声、湿声 squelch、无缝循环交叉淡化、房间混响冲激响应、按响度对齐 |
| `src/platform/sfx/recipes.ts` | 每个声音的配方：变体数、混音电平、混响送量、冷却时间、同时发声数、是否循环 |
| `src/platform/sfx/player.ts` | 解锁音频后，在空闲时间分片把配方渲染成 AudioBuffer（尚未渲染时现场渲染）；播放时轮换变体、±4% 音高和音量抖动，按画面位置定声像，送入共享的房间混响，并限制每个声音的同时发声数；管理循环音 |
| `src/platform/sfx/director.ts` | 决定播放什么：模拟事件按材质、蓄力、死因、机关类型映射到具体声音；连续状态驱动的声音每帧从状态推出（脚步、冲刺收势、坠落起跳、入场呼啸/落地、燃烧/召回/遥控/蓄力/地火/机关循环、出界警告、引信滴答） |

音乐（`audio-score.ts` 里的 Tone.js 配乐）不变。音效总线和音乐总线之后仍是同一个限幅器。

## 设计要点

- **飞镖投掷**：带通噪声扫频，再加 18–26 Hz 的幅度调制，做出回旋镖旋转的“呼呼”感。蓄力越满，音高越低、时间越长，满蓄力再叠一层低频冲击。
- **弹镖、对砍**：金属杆的非谐泛音比例 1 : 2.756 : 5.404 : 8.933，加微失谐的成对泛音产生拍音，再叠回旋镖本身的木质声。满蓄力弹镖更低更长，加低频轰声和镲片尾音。对砍是两记较闷的金属声加刮擦。
- **材质**：反弹声按命中的障碍物材质区分：石头（清脆短促）、木头/箱子（中空敲击）、树（更低的木声加树叶）、竹子（接近谐波的管音，略微下滑）、灌木（沙沙声）、飞镖对撞（两记木声）。
- **死亡**：切开 = 高频 shhk 声 + 湿声 + 低频闷击 + 碎裂；落水 = 下沉“咕咚” + 水花 + 30 个上滑气泡；冰冻后击碎 = 一团高频碎片声；烧死 = 噗声 + 嘶嘶 + 噼啪；出界 = 电流 zap 下滑。切开后 0.55 s 补一声扑倒在地。
- **脚步**：节奏与人物动画一致：一个走路循环 0.65 s 走两步，乘以 `move_speed_parameter`。每个玩家音高不同，与 Godot 按玩家区分音高的做法一致。走进植物时有沙沙声，在湿地上有滑行循环音。
- **响度**：每个声音渲染后先按最响的 50 ms 窗口的 RMS 对齐到同一响度（不超过峰值上限），再用配方里的电平定混音层级：爆炸最响，其次是死亡和满蓄力弹镖，脚步和普通投掷这类高频出现的声音偏轻。

## 覆盖

`/dev/sfx.html` 对照 Godot 与原版引用的 153 个 FMOD 事件，Web 有对应的从 65 个增加到 90 个。新补上的有：脚步、冲刺收势、扑倒、边缘起跳、入场呼啸/落地、召回/遥控/蓄力循环、燃烧循环与熄火、冰冻碎裂、解冻、出界警告、小水花、云雾、地面起火/燃烧循环、植物沙沙、湿地滑行、替身被打掉、引信滴答、“开始！”。

仍然没有对应的主要是：菜单 UI 音效、黄金回旋镖/团队/躲猫猫模式（Web 没有这些模式）、咖啡/辣酱/盐和胡椒的专属死亡、关卡环境底噪，以及道具书被摧毁（Web 还没有对应事件）。

## 验证与局限

- 我听不到声音，所以客观检查做的是：
  - 全部配方渲染无 NaN、首尾无爆音、循环首尾衔接平滑、同一种子结果一致；
  - 在 headless Chromium 的 OfflineAudioContext 里走完整 WebAudio 链路（声像、混响、电平）；
  - 用频谱图检查每个声音的形状（`test-results/sfx-sheet.png`，不进 git）。
- **好不好听要靠人耳判断。** 用 `npm run dev` 打开 `/dev/sfx.html`，可以逐条试听 Web 音效，并加载原版音频对照（原版音频只在本地读取）。调音时改 `recipes.ts` 里对应配方的参数或 `gain`。
- 测试：`tests/sfx-bank.test.ts` 覆盖渲染有效性、可复现、响度上限、事件映射（蓄力、弹镖类型、死因、爆炸类型、替身）、按障碍物判定材质，以及脚步节奏。
