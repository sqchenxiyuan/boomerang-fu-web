# 地面与水面质感

日期：2026-11-18。地面原来是一整块纯色挤出体，水面是一整块纯色平面，近看很平。这一轮给两者加了程序化细节，只改表现，不改模拟，`SIMULATION_VERSION` 不变。实现集中在 `src/rendering/surfaces.ts`。

## 做法

全部图案在着色器里按世界坐标（木板按物体局部坐标）现算，不用任何贴图文件，所以不引入素材，同一张图每次看到的纹理都一样。

**地面**（`GroundMaterial`）：在 `MeshStandardMaterial` 上打补丁，光照、阴影、雾都保留。按地面类型分五种：

| 类型  | 用在哪                                           | 图案                                         |
| ----- | ------------------------------------------------ | -------------------------------------------- |
| grass | 花园风格地面、孤岛/云朵/桥梁类地图的草地         | 大块明暗色斑、暖色日照斑、零星浅色和深色草点 |
| sand  | 神庙风格地面（箱子、木筏、齿轮、神庙、陷阱等）   | 沙丘起伏和斜向风纹                           |
| stone | 水上风格地面（码头、河流等）、下落地砖、圆形平台 | 不规则石板拼接，每块深浅不同，石缝柔和       |
| wood  | 木地板、木筏                                     | 沿局部 x 方向的木板、错开的接缝、木纹        |
| ice   | 冰地板                                           | 长条反光和浅色细裂纹，粗糙度降到 0.42        |

侧壁统一加了上浅下深的渐变和隐约的地层；草地和沙地的侧壁顶上有一圈草皮/沙壳边。内置的五张自定义地图按主题选类型（garden、canal 用草地，sandstone 用沙地，ruins 用石头）。

材质做成子类而不是给实例挂 `onBeforeCompile`，原因是动态地板会 `clone()` 一份去做预警变色，像素风的静态体素网格也会克隆材质（加每格明暗贴图），子类的克隆会带上补丁。所有地面材质共用一个着色器程序，只有 uniform 不同。

**水面**（`WaterMaterial`）：

- 离岸距离场：建图时把静止的陆地（不动、站着的地板，加上静止障碍的占地）扫描成网格，再做两遍欧氏距离变换，得到每个点到最近岸边的带符号距离，存成单通道纹理。网格最细 0.1，最长边不超过 384 格。
- 近岸浅、远处深：按离岸距离在浅色和深色之间过渡。
- 岸边浪花：贴着岸有一圈断续的白边，另有一道浪从岸边往外推约 0.7，边走边淡出。
- 水面起伏：两层反向漂移的噪声做柔和的明暗起伏，稍微扰动法线让反光跟着动，再加零星的闪光点。早先用过噪声等值线画波峰，看起来像一条条虫子，已去掉。
- 下落地砖掉下去或升回来时，陆地集合变了，距离场按需重算（复用同一张纹理），浪花跟着变。木筏这类移动地板不参与，周围没有浪花。
- 动画用模拟时间驱动（`setSurfaceTime`），所以回放和拖动进度时水面一致。

**像素风**：`setSurfacePixel(0.1)` 后，所有图案按体素格量化：地面色斑落到每个方块，木板变成块状，浪花和水面起伏变成硬边色阶，细线类细节（草点、石缝、木纹、冰裂纹）关闭，交给原有的每格明暗贴图。原来的 8×8 像素水面贴图已删除。

## 成本

- 距离场构建：在负载很高的本机（4 核、负载 11–16）上，58 张原版地图（含教程）最慢约 27 ms（Enclosed，72 个障碍），大多数在 20 ms 以内。只在建图和下落地砖变化时算。
- 着色器：新增两个程序（地面、水面），像素风再多一个带贴图的地面变体。
- 帧率：本机只有软件渲染，又和别的基准测试抢 CPU，新旧版本在孤岛图上都只有约 1 帧/秒，差异被噪声淹没，没法给出可信结论。进入对局后前两帧的耗时，新版两次 10.0 s / 6.3 s，旧版 6.8 s / 3.9 s，可能多了编译时间，但样本太少。有 GPU 时预计无感。

## 和 MUNDI 的关系

MUNDI 的嵌入页用的是同一个渲染器，但它使用的是已导入的 0.10.0 构建，这次改动不会自动进去。要带过去需要重新 `build:mundi` 并导入。导入前建议在低配或软件渲染环境开一局孤岛、弹珠台这类重地图，确认第一步没有因为多出的着色器编译碰到平台的 5 秒看门狗。
