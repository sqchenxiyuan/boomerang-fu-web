# 第一版实现与验收约定

> 历史记录：对应第一版，后续 SDK 分层和动作时序已经调整。当前接口见 [sdk-api.md](sdk-api.md)，当前机制证据见 [mechanics-and-feel.md](mechanics-and-feel.md)。

目标：完成可在浏览器独立游玩的 Boomerang Fu 核心玩法复刻。范围沿用初查结论：单张竞技场、玩家对机器人、本地双人、冲刺、近战与反弹、投掷/回归/落地/召回、一击淘汰与完整回合计分，以及护盾/加速/爆炸三种强化。使用自建简模与合成音效；本轮不承诺全部原版模式、资源、联网或逐帧一致。

## 依赖方向

`main → application → simulation / input / rendering / UI / audio`

- `src/core`：纯数学、碰撞、种子随机数、类型、调参数据，无浏览器和 Three.js 依赖。
- `src/simulation`：60 Hz 纯逻辑，持有唯一权威状态；角色、投射物、伤害、强化、机器人和对局分别维护明确职责。输入采用帧命令，显示和音频采用事件。
- `src/rendering`：读取状态并插值，负责相机、场景、角色姿态与短期粒子；不修改模拟状态。
- `src/platform`：键盘/手柄、固定步长时钟、Web Audio。暂停与失焦时清除缓存输入，避免意外发射。
- `src/ui`：菜单、HUD、教程提示、回合/胜负界面。UI 命令由应用层转发，不能直接修改角色字段。

战斗判定顺序：读取输入与 AI → 角色移动 → 近战 → 镖的扫掠运动/碰撞 → 强化 → 回合裁定。同一 tick 的淘汰统一裁定，允许平局。每发镖维持一个可恢复的武器归属，反弹改变伤害归属而不复制库存。事件只消费一次，帧率不能改变规则速度。

## 必须覆盖的验证

1. TypeScript 严格检查与正式构建成功，运行时无资源/脚本/WebGL 错误。
2. 圆与墙体碰撞、连续扫掠、防穿透、召回、接取、近战反弹、冲刺无敌、护盾消耗和爆炸范围有独立规则验证。
3. 击杀、平局、回合重置、比分延续、整场结束和重新开始正确；机器人多种种子对局能够正常结束。
4. 真正浏览器中用 UI 开始、键盘移动/挥砍/蓄力释放/冲刺、暂停恢复、重新开局；验证双人输入彼此独立。
5. 查看实际渲染截图；验证 1440×900 和较小窗口的取景、HUD、菜单与文字不遮挡关键操作。
6. README 写清启动、操作、结构、已实现范围与相对原版的差异。

## 逆向参数使用原则

沿用原版可确认的时序语义：按住蓄力、释放投掷，空手按住召回；冲刺约 0.2 s；近战约 0.2 s；攻击冷却参数 0.66 s；位移与碰撞在二维进行。Web 世界尺寸与速度按本地图缩放，具体值集中在配置文件中；不把原版施力字段误称为最终速度，不把简化后的轨迹宣称为原版完整公式。
