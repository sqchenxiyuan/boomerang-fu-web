# 第一版验收记录

验证日期：2026-10-28（Asia/Shanghai）。实际目标是单张竞技场的核心玩法 Web 复刻，不是完整商业游戏的全部内容。

## 功能与权威证据

| 要求 | 实现 | 验证 |
| --- | --- | --- |
| 独立浏览器游戏 | Vite 构建、Three.js 场景；无原版运行时依赖 | `npm run build`，Chrome 实际打开与绘制；无加载失败和脚本错误 |
| 结构分层 | `core → simulation`；应用组合 input/render/UI/audio | 严格 TS 检查；规则测试直接导入模拟层，不引入 DOM/WebGL |
| 移动与碰撞 | 扫掠圆、圆角矩形、墙体滑动、二维规则 | `collision.test.ts`，浏览器双人移动 |
| 冲刺/水坑 | 限时冲刺、伤害免疫、走路边缘保护、落水淘汰 | 伤害单测；浏览器通过按键连续完成 5 次落水回合结算 |
| 近战/反弹 | 持械攻击、正面招架、反弹归属、空手缴械 | `combat.test.ts`；浏览器 J 键触发挥砍 |
| 飞镖完整流程 | 蓄力、释放、曲线、有限追踪、反弹、返回、落地、召回 | 高速击中/墙先于人、反弹归属、返回库存、落地召回单测；浏览器 K 蓄力释放与召回 |
| 召回不误发 | 接住召回镖后阻止同次按键的释放投掷 | 独立回归测试 + 浏览器保持按键到接取后松开验证 |
| 三种强化 | 护盾、加速、爆炸；书本生成和 HUD | 护盾/范围伤害/掩体测试；加速增加实际移动距离并缩短冲刺恢复，重复拾取不重复占槽；四人对局中产生拾取、护盾与 24 次爆炸 |
| 机器人 | 确定性随机数、有限决策频率、路径规划、进退/投掷/闪避/反弹 | 3 个双人种子与 1 个四人种子均完成整场；双人获胜来自实际战斗击杀 |
| 对局循环 | 倒计时 → 战斗 → 回合结算 → 下一回合 → 五分胜利 | 单测覆盖分数只计一次、平局、重置；浏览器真实五回合 → 冠军面板 → 再来一场 |
| 本地多人 | 独立键位，1P/2P，最多四角色 | 浏览器分别驱动两位玩家，检查另一位位置不受影响；四角色开局 |
| 暂停与焦点 | Esc/UI/Start、失焦暂停、输入清空、固定步长冻结 | 浏览器暂停期间模拟时间不变，暂停前按住 K 松开不会误投；触发 blur 事件验证处理器 |
| 手柄 | 标准 Gamepad API 映射 | 注入虚拟 Gamepad API，验证移动轴和 Start 暂停/恢复；未测试实体硬件 |
| 布局与显示 | 1440×900 与 960×640 | 人工查看实际截图；小窗口无横向溢出，四人比分与操作区可见 |

`scripts/browser-verify.mjs` 使用本机 Chrome、真实页面点击与键盘事件；只读取开发期诊断快照，不修改游戏状态。浏览器验证输出在本机 `test-results/browser-verification.json`，截图包括：

- `v1-menu.png`：开始页面。
- `v1-local.png`：双人对局。
- `v1-paused.png`：暂停。
- `v1-victory.png`：五分冠军面板。
- `v1-small.png`：960×640 四人场景。

开发调试接口 `window.__garden` 仅提供只读快照和渲染统计，并由 `import.meta.env.DEV` 限定；正式构建不会暴露该接口。

正式构建通过 `node scripts/production-smoke.mjs` 单独验收（先执行 `npm run build` 并在 4173 端口运行 `npm run preview`）：检查产物 JS 不含调试接口或原版安装路径，Chrome 打开正式页面后确认接口不存在；通过真实按键操作移动、近战和蓄力释放，确认双人 HUD、计时与暂停恢复正常。结果为 `passed: true`，页面/资源错误和外部资源请求均为空，保存在 `test-results/production-verification.json`；截图为 `production-menu.png`、`production-game.png`。

## 重要修复

- 召回接取与再次投掷分离，避免释放同一个 K 键立即误发。
- Start 系统按键独立于暂停中的模拟时钟轮询，手柄可恢复暂停。
- 角色互相挤开时也通过墙体碰撞检测，避免在人群接触中被推出墙面。
- AI 近战冷却时会拉开距离，避免双方长期面对面重复招架。
- 取消外部字体请求，正式运行只需站点自身的文件。

## 与原版的边界

时序与交互来自已保存的本地 C# 重建及资源证据；本轮未启动原版做逐帧手感采样。显示使用自建简模和程序动画，地图为按原版设计语言制作的一张庭院；没有宣称模型/场景完整导入、原版全部强化、原版 AI 等价或网络联机已经完成。当前第一版验收以本文件开头列出的范围为准，与最初首版提议一致。
