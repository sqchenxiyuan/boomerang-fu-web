# 画面复查：和传送门同类的问题

日期：2026-11-18。传送门修完后，用户要求"仔细复查一下有没有类似问题"。传送门暴露出四类毛病，这次按这四类把所有地图过了一遍：

1. 被墙或地面吞掉、互相穿插；
2. 像素风下没被体素化，还是平滑的；
3. 在浅色地面上颜色发白、看不清；
4. 和玩法有关、却不够显眼。

只改表现，不改模拟，`SIMULATION_VERSION` 不变。

## 怎么查的

- **脚本扫描**：在浏览器里用真实的 `GameRenderer` 加载全部 63 张图（58 张原版、5 张内置），切到像素风，列出场景里所有没被体素化的物件。结果只有三类：
  - 水面（有意保留）；
  - 这次新加的传送门光效（有意保留）；
  - 冰面覆盖层：7 张图共 11 块；
  - "跃迁花园"传送台的圆环。

  运行时生成的东西另外查了代码：道具光圈、角色和飞镖的影子、近战拖尾、边界线都是平滑的。

- **遮挡探测**：对每块冰面按网格从上往下打射线，看有没有被地面盖住。被判成"盖住"的几处，其实都是冰面上方本来就有的转子和压板，冰面没有被体素地面吞掉。
- **逐张近看**：开关、要塌的地砖、陷阱、冰面、道具、水面都在两种风格下截了近景，并对照 Godot 版（`arkevo-games` 里的 `original_switch_visual.gd`、`original_floor_hazard.gd`）。

## 发现并修掉的

## 看过、没改的

- **陷阱地砖平时和普通地砖一样**：没有找到原版平时有区分的依据，保持原样，靠预警。
- **道具书本**：颜色和形状都够显眼，只改了光圈边数。
- **近战拖尾、边界线、名牌**：属于动态特效和界面，平滑的样子在像素风下也能接受，这次没动。
- **软件渲染下的帧率**：这台机器只有 SwiftShader，测不出可信数字。新增的绘制只有每个开关一次地面光，冰面在像素风下是几百个四边形。

## 测试

`tests/hazard-visuals.test.ts`：

- 冰面用冰材质，平滑几何的边缘属性为 0；
- 像素风冰面的每个角点都落在体素网格上、面积和原形状吻合、有边缘格、法线朝上；
- 开关可用时发光，用掉后熄灭；
- 被击中时闪成击中者的颜色并按 (1−t)² 回落；
- 塌陷和陷阱地砖的红色预警强度和曲线；
- 像素水面闪光的概率和浅水带限制。
