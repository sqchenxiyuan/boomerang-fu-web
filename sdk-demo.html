准备中

接管会暂停原控制器。恢复后脚本继续运行；旧的外部控制凭据失效，需要重新获取。

外部动作

选择外部注入后按住按钮，持续提交动作；松开投掷键出镖。


          

        

      

      

        JavaScript 接入示例
        
const game = createBrowserGame(container, { match: { mapId: 'portals' } });
const input = game.session.acquire(0, 'my-agent');
input.submit({ move: { x: 1, y: 0 }, throw: true }, 6);
// 继续提交完整按钮状态，松开时 throw: false。
const human = game.session.takeover(0, 0);
human.release(); // 恢复原脚本；外部来源需重新 acquire。
game.session.useScript(0, ({ state, actorId, tick }) => ({ move: { x: 1, y: 0 } }));
